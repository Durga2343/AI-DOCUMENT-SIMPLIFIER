## 📌 About The Project

Understanding lengthy and complex documents can be difficult and time-consuming.

**AI Document Simplifier** is a web application designed to make document understanding easier. Users can upload documents and use Artificial Intelligence to analyze the content, generate simplified explanations, summarize important information, and extract key points.

The project combines **MERN Stack technologies with Generative AI** to provide an interactive and user-friendly document analysis experience.
